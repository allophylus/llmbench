games, side by side

Four browser games, one frozen prompt each, the same models. Every game is generated as a single self-contained HTML file drawn with three.js, then graded in a headless browser: it must run, and a grader drives it through a small published state object and checks the rules numerically (determinism, counts, economy, stability). Assertions = rules verified by execution. Compliance = did it build what was asked, and only that (0-100, points off for extras the task did not request). Attempts = generations used, including up to 10 repair turns after a failure. Live frames are playable; a failed build shows its last screenshot.
