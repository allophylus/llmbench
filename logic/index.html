everyday logic traps

Ten one-line questions people actually ask, each with an obvious-looking wrong answer. Every model answers all ten twice: once with its reasoning channel disabled, once enabled. The only difference between the two arms is the thinking switch — same server, same temperature 0, same fixed seed, same token cap (8192), one question per request, fresh context, no examples. Grading is strict: the model's final Answer: line must match the expected answer exactly. No partial credit. A model that runs out of tokens before committing to an answer is marked T and left out of the score rather than counted wrong.

Read this before trusting the ranking. Questions 3, 4 and 5 (bat+ball, widgets, lily pads) are the classic Cognitive Reflection Test and are almost certainly in training data; the other seven are fresh everyday traps of the same shape. A model failing a classic item is more damning than failing a fresh one, because it had every chance to memorise it. Passing a classic proves much less. The per-trap matrix marks memorisable items with * so you can judge each result yourself.
