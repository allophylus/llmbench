About this table

Every row is folded from one or more raw SCHEMA-1 run records produced by the benchmark suite; the per-row JSON files under raw/ are copies of the originals. Cells are percent correct on frozen prompt sets. The Decode / Prefill columns are pp512 (prefill) and tg128 (decode) tokens/s from llama-bench; the Server ctx / speed columns come from a live server: a cold request at temperature 0, cache_prompt:false, reading the server's own prompt_per_second and predicted_per_second. VRAM is the GPU's used-memory peak during the request. Videos are served from a CDN and only appear when the render exists. Every number here can be checked against the machine-readable dataset (data/results.json, plus the per-question chat JSONs); how each family of numbers is produced is on the method page.
